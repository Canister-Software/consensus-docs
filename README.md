This repository contains the documentation site for the Consensus Protocol. The protocol is a decentralized HTTPS proxy network for coordinated execution of side-effectful HTTP requests and metered WebSocket sessions. It canonicalizes requests, deduplicates identical calls, and returns deterministic responses across replicated systems.
